# 3CODE & SLIC 모바일 정보찾기 (CPK)

지역별(`ASIA`, `EUR`, `US`) **3CODE**, **SLIC**, **DEST(목적지)** 정보를 모바일에서 빠르게 검색하고 추가·수정·삭제할 수 있는 웹 어플리케이션(PWA)입니다.

## 모바일 접속 주소 (GitHub Pages)
- **웹앱 바로가기**: https://ankijung88-cloud.github.io/CPK/

> 스마트폰 브라우저(Chrome / Safari)에서 위 주소로 접속한 뒤 **"홈 화면에 추가"**를 누르면 앱처럼 바로 실행할 수 있습니다.

## 주요 기능
1. **통합 실시간 검색**: `3CODE`, `SLIC`, `목적지명`, **한글 초성**(예: `ㄴㄹㅌ`, `ㅍㄹㅋㅍㄹㅌ`) 실시간 필터링
2. **지역별 필터 탭**: `전체` / `ASIA` / `EUR` / `US` 탭 전환 및 건수 표시
3. **데이터 추가·수정·삭제**: 항목 터치 시 수정/삭제 및 우측 하단 `＋ 코드 추가` 버튼 지원 (기기 내 자동 저장 및 원본 데이터 복원 지원)
